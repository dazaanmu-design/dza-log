DZA Log

Repo sudah siap. Silakan upload file index.html dari ZIP deploy (via GitHub → Add file → Upload files), lalu aktifkan GitHub Pages.

  1. Buka repo ini di GitHub
  2. Add file → Upload files → pilih index.html dari ZIP
  3. Settings → Pages → Source: Deploy from branch → main / / (root)
  4. Tunggu 1–2 menit, buka: https://dazaanmu-design.github.io/dza-log/
